# Astral Workshop 0.21.0

Mythical Uniques now have corrected equipment types, item effects and visible loot beams. The compendium includes the current 53-variant catalog.

- 43 ESR-inspired Mythicals, three Mageblood belts and seven strong Screams of the Desiccated belts. Other Screams variants no longer drop; saved row IDs remain stable.
- Trial-only production drops: 1:5000 base chance per native loot roll on Players 1. No guaranteed Corpsefire drops in this release.
- Jewel-style sky beam and ground glow for every Mythical. Mageblood, Screams and Headhunter are belts.
- Normal item skills and procs use level 60. Natalya retains level 25 with 5% on kill. Mephisto's Nightmare has 15% level-60 Hydra and enemy fire resistance reduction.
- Native proc handlers corrected, including Thunder Storm. Starfall now rains high-damage magic stars; Voidforge adds 1000–2000 fire, cold and lightning damage each.
- Timed Empowerments have Buff HUD entries. Blood adds life steal and bleeding; Underworld boosts poison, magic and physical damage for 12 seconds.
- Renewal regeneration is displayed. Ties poison damage reduced tenfold. Skeleton Warrior/Mage minion-life scaling and tooltip calculations corrected.
- Includes the accumulated shared-stash organizer, alternating row/column sorting, treasure goblins and Trial updates.

## Save compatibility and testing

This build uses the separate ReimaginedWorkshop-v2 save profile and expanded item-stat storage. Legacy ReimaginedWorkshop saves are left untouched: do not copy them into v2. Existing v2 items keep their rolled stats; obtain new drops for revised damage and proc levels. Remove old misclassified belts from the boots slot and re-equip. Re-summon skeletons after equipment changes.

Native builds, runtime regression checks, table validation, save-width checks and website rendering checks passed. The latest proc visuals, Buff HUD behavior and item effects still need in-game testing.

Install or update with the launcher. Existing launcher installations detect this mod release on Play / Check and repair. The installer also supports fresh launcher installations.
