# Astral Workshop 0.25.0

- Launcher 0.3.0: select monster density x1 through x5 in Settings. The setting persists through updates; x1 restores the release baseline.
- League Orb stash hover tooltips show crafting effects for weapons, armor/shields and rings/amulets, plus the tier-specific level cost.
- Goblin spawn rolls tripled: 30% per eligible world area and 3% per eligible Trial wave.
- Bow Mastery: doubled flat fire/cold/lightning damage. Adds Dodge/Avoid/Evade: 5% at level 1, +1 percentage point per additional level, maximum 35%.
- Deathfire: Life on Hit ranks reduced from 10/10/10/20 to 2/2/2/5.
- Hexblade becomes Bloodthirster: 50% chance to cause Bleeding replaces the Plague proc.
- Blood Drinker becomes Berserker: +1 to Rage (All Classes) replaces life steal. Rage damage scaling now works for other player classes.

Reapply the Astral tree with Apply to update an existing inscribed Sigil. Restart the game after updating. The save profile remains ReimaginedWorkshop-v2.

Validation: native combat suite, Astral payload regressions, generated data/tooltip checks and launcher tests passed. Manual in-game verification of these changes remains pending.
