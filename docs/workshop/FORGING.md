# Rune forging reference

Version 0.6.1. Transmute the listed runes together with one eligible item to forge directly. No Identify scroll is needed. The item base selects the matching word, with narrower bases taking precedence. White is the default for the identical Dol + Io wand recipes; Shadow of Doubt remains available through the optional older seal path. Older seal recipes and cycling with an Identify scroll still work.

All selected effects retain their original full values. Magic gets the core plus up to four prioritized positive modifiers. Rare/Crafted gets the core plus up to two. Unique/Set gets the core only. Normal/Superior gets all effects including intrinsic rune bonuses.

The wording below follows the approved German balance workbook. Names, restrictions and rune recipes come from the pinned Reimagined source tables.

## 0.12.18 inspection and compatibility

Runeforged labels now resolve the actual hovered item even when equipped, independently of requirement-tooltip callbacks. Newer loaders use ItemDetails. The deployed ABI-1 loader uses its byte-guarded client lookup after public handle validation, then verifies type, class and runtime ID before reading saved marker fields. No pointers are retained.

Lore still grants one additional all-skills property to set/unique helmets. Authority retains its approved full-strength core. All 220 definitions and generated bundles are audited; no blanket stat rebalance was applied. The reported Cathan's Visage case still requires checking its live item and player bonuses. Forge logs now record all-skills before/after application for this diagnosis.

Missile-weapon recipes now additionally accept the native `thro` category, including javelin-class Glaives. Existing bow/crossbow recipes stay intact. All 23 misleading `Merc Equip` helmet labels were corrected in the workbook and canonical data.

Dim Vision (Curse Mastery) and Weaken are passive in Workshop and cannot be cast by an item trigger. Their proc references now use active Decrepify, preserving chance, skill level and trigger event. Runeforges affected: Glammer, Gloom, Obsession, Purity, Shadow and Youth. The same correction covers 8 magic suffixes, 22 unique items, 5 set items and one monster-property row (plus mirrored base tables).

Verified: all proc targets active, idempotent application, table diffs change only skill targets, native DLL build and Chronicle fixtures pass. Existing items retain their saved properties; no character saves are rewritten. New drops and newly applied forge bonuses use the correction.
