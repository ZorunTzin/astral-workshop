# Astral Workshop

An offline Diablo II: Resurrected mod built on Reimagined.

- **Runeforging** — 220 recipes for custom forged equipment.
- **Astral passive tree** — additional ways to shape your build.
- **Class reworks** — redesigned skills and new build options.
- **Astral Trials** — wave-based endgame challenges and craftable Trial Seals.
- **Loot Filter & Chronicle** — filter your drops and track your collection.
- **Windows launcher** — automatic mod updates before you play.

Visit the **[Astral Workshop website](https://astral-workshop-compendium.chattyactor2.chatgpt.site)** for the full compendium, gameplay details and launcher download.
