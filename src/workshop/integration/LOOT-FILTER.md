# Native Loot Filter and Chronicle

Escape > Loot Filter opens the built-in D2R rule editor: profiles, rule ordering, enable/disable, copy, import and export. Escape > Chronicle opens the built-in Unique / Sets / Runewords collection and rewards interface. Native game assets and save logic provide these panels; Workshop only restores their missing pause-menu entries.

The earlier ESR 1.5.1 plugin is retired as .dll.disabled and disabled in its config. Existing JSON profiles remain untouched as backups; they are not native profile codes and are not automatically imported. Create a native profile in the in-game editor. No discovery progress or rewards are granted by this integration. Chronicle uses the current mod item tables and native discovery rules.

Native menu templates were read from the user's installed D2R data. Runtime verification is required after restarting the game.
