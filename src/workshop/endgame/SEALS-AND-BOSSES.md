# Trial seals and milestone waves (0.20.3)

Blank Wt1-Wt5: 1x1, compact currency, native Materials slots next to the seven orbs. Akara test stock: 1 gold. First Awakening/Ascension/Corruption cube operation outputs noncompact Wa1-Wa5 with saved modifiers. Existing Wa seals remain compatible and never enter the currency counter. Blank seals also open portals directly; portal capture clears any prior modifiers for that tier.

World drops: independent 0.1% per eligible Hell non-quest TC roll. Tier weights 10/6/4/3/2. Original loot is preserved through a -2 pick wrapper; quest tables remain unchanged. Trials use the same branch alongside materials and orbs.

Every tenth wave adds one private act-boss copy (Andariel, Duriel, Mephisto, Diablo, Baal), five champions and two one-modifier elites. These eight are additional to normal density. Forced escort ranks override one-wave champion/elite cards. Boss copies have separate IDs and no quest TC; their ordinary loot uses the arena branch. Existing test HP scaling remains active. Boss death is tracked even if its corpse disappears. Choice waits for every tracked enemy and the existing 3 seconds.

Next wave is shown upper left using native digit widgets. Token of Absolution socket moved to the spare right margin to fit all 12 Trial materials without overlap.

Validation: repeated data generation, stash collision/type checks, blank-to-crafted recipe guards, table hashes, milestone 9/10/11/20 counts across five trials, explicit rank precedence and boss death/choice runtime fixtures. In-game boss AI, visuals and first bank conversion still require player testing.

Loot goblin wave: legendary-only card with 1% chance per offer roll, respects banish, replaces exactly the next wave including milestone bosses. All seven parent families are eligible. Native loot and flight remain active; Sire children keep the wave open. Escapes resolve the encounter without granting kill loot. Regular Goblin chance is suppressed during this event.
